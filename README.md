# MeetMates

**Планы и люди, с кем их разделить.** Веб-сервис, который помогает найти компанию
на конкретное занятие — и повторить встречу с теми же людьми.

Механика знакомства взята из дейтинга (свайпы), романтического контура нет вообще.

## Продукт в одной таблице

| | |
|---|---|
| **Для кого** | 18–35, Киев. Primary — переехавшая: круг остался в другом городе `D-21` |
| **Что делает** | Даёт плану компанию, а компании — продолжение |
| **Единица** | **Запрос на компанию**: занятие + сколько нужно, по умолчанию `+1` `D-22` |
| **Вход** | Колода людей, swipe-first `D-10` |
| **Отличие** | План как самостоятельная единица + репутация из проверяемых фактов. Ни того, ни другого нет ни у Tinder, ни у BFF, ни у Peanut, ни у Meetup |
| **Платформа** | Мобильный веб, 390 × 844, английский UI |
| **Этап** | Кликабельный прототип на мок-данных, без бэкенда `D-01` |
| **Деньги** | v1 бесплатен, целевая модель не выбрана `D-28` |

**Главный риск — плотность, а не идея.** Широкий сегмент при малой базе даёт разреженную
ленту; пустые состояния проектируются раньше заполненных (§2.1, §4).

## Что входит в MVP

| Блок | Что в нём |
|---|---|
| **Профиль** | Анкета, фото, теги интересов, пол опционально, предпочтения по радиусу |
| **Колода** | Swipe deck с общими интересами первой строкой, фильтры, профиль, match modal |

## Инварианты

Правила, которые не нарушаются ни на одном экране. Нарушил — значит экран неверный.

1. Точная геолокация человека не показывается никогда — только округлённое расстояние.
2. Report и Block доступны везде, где виден другой человек.
3. Написать в личку можно только после взаимного лайка; исключение — подтверждённый отклик.
4. Точный адрес встречи виден только подтверждённым участникам.
5. Гендерного фильтра в колоде нет; ограничить отклик можно только своим полом.
6. Ни одного намёка на деньги в v1.
7. Ни один экран не тупик при пустых данных.

Полный список с обоснованиями — [CLAUDE.md](./CLAUDE.md), Рабочие соглашения ·
применение — [design-system/](./design-system/).

## Что известно о людях и чего нет

Интервью **не проводились**. Всё ниже — кабинетный ресерч с уровнем источника:
**A** рецензируемое и официальное · **B** коммерческая аналитика · **C** блоги · `[?]` источника нет.

| Знаем | Не знаем |
|---|---|
| Сегмент есть: 442 438 ВПО в Киеве, ~12 % города (**A**) | Ищет ли primary компанию через приложение: в 100 объявлениях переезд упоминают **двое** |
| Дружба требует повтора: 40–60 часов до приятеля (**A**) | Сколько встреч достаточно в нашем формате |
| Организаторов в Киеве 0,03 %, медианная явка 2 | Сколько людей позовут компанию, если отвечать за неё не надо |
| Каждое пятое объявление о знакомстве — про компанию | Придёт ли этот спрос к нам: каналы, где он измерен, мертвы |

Персоны — [persones.md](./research/persones.md) · jobs и матрица — [jtbd.md](./research/jtbd.md) ·
шесть закрытых вопросов — [research.md](./research/research.md).

   что человек делает сегодня, пойдёт ли он на встречу с незнакомцем. План — [plan.md](./research/plan.md).
2. **Вайрфреймы пяти флоу** — начиная с пустых состояний, а не с заполненных.
3. **Визуальная концепция на четырёх экранах.**
