# MeetMates

Поиск единомышленников для совместного времяпрепровождения.

Веб-сервис, который помогает находить друзей со схожими интересами, общаться с ними
и вместе ходить на мероприятия — на основе интересов, предпочтений и местоположения.

**Полный бриф — [CLAUDE.md](./CLAUDE.md). Это источник правды по продукту.**

## Люди

Что известно о пользователях — и что нет. Интервью не проводились: всё ниже собрано
по кабинетному ресерчу и помечено по уровню источника.

**[research/persones.md](./research/persones.md)** — четыре персоны. **Даша** (primary) —
переехала в Киев, самый большой измеримый сегмент: 442 тыс. ВПО. **Максим** — друзья
разъехались; самая тонкая по данным. **Оля** — нужна компания для хобби. **Артём** —
организатор, сторона предложения, ~1%. У каждой: контекст, jobs, боли, триггеры доверия,
цитата-настроение из реального источника — или `[?]`, если не найдена. Внизу — сводка,
что подкреплено, что нет.

**[research/jtbd.md](./research/jtbd.md)** — иерархия jobs в формате «Когда / я хочу / чтобы»,
без названий функций: main job, пять related с моментом, провалом и проверкой,
эмоциональные и социальные, гипотезы без данных. **JTBD-матрица** job × персона ×
функция × рынок — все оценки важности `[?]`. Ядро MVP как гипотеза из трёх jobs
и функции-кандидаты на вылет.

**Главная дыра:** размер сегмента primary измерен, спрос в нём — нет. Три точечных
вопроса, которые её закрывают, — в [research.md](./research/research.md), раздел
«Доисследование после персон». Короткая выжимка — в [CLAUDE.md](./CLAUDE.md), §2.2.

## Порядок работы

```
research  →  wireframes  →  concept  →  tokens + components  →  design-system  →  handoff  →  prototype
```

Этапы идут последовательно не догматически, но правило одно: **визуал не начинается,
пока флоу не проверен на вайрфреймах**, а компоненты не собираются, пока не утверждён концепт.

## Что входит в MVP

- **Профили и интересы** — анкета, фото, теги интересов, предпочтения по компании и радиусу.
- **Поиск людей** — swipe deck с подсветкой общих интересов, фильтры, экран профиля, match modal.
- **Чат 1-на-1** — открывается после взаимного лайка; ice-breaker подсказки.
- **События** — лента, карточка события, Join/Leave, создание события, групповой чат участников.

Навигация — четыре вкладки: **Discover · Events · Chats · Profile**.
Полный список экранов и user flows — в [CLAUDE.md](./CLAUDE.md), §6.

## Продуктовые инварианты

Правила, которые не нарушаются ни на одном экране:

1. Точная геолокация не показывается никогда — только округлённое расстояние или район.
2. Report и Block доступны везде, где виден другой пользователь.
3. Написать в личку можно только после взаимного лайка; исключение — групповой чат события.
4. Точный адрес события виден только участникам после Join.
5. Никаких платных фич и paywall в v1.

Подробнее — [design-system/README.md](./design-system/README.md).

## Визуальный тон

Энергичный и яркий: brand-градиент violet → pink на акцентах, мятный акцент успеха,
крупная типографика, скруглённые карточки, spring-анимация свайпа. Фон светлый —
яркость даётся акцентами, а не заливкой экрана. Значения — в [tokens/](./tokens/).
