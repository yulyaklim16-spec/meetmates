# handoff

Всё, что нужно разработке, чтобы собрать продукт без вопросов «а как здесь должно быть».
Наполняется, когда концепт и компоненты утверждены.

## Состав

- **Спецификации экранов** — размеры, отступы, поведение при скролле, что на первом экране.
- **Карта состояний** для каждого экрана: обычное · пустое · загрузка · ошибка · офлайн.
- **Спецификация свайпа** — порог срабатывания в px и в градусах поворота, поведение
  при отпускании до порога, появление лейблов LIKE/SKIP, undo.
- **Переходы между экранами** — что анимируется, чем и сколько миллисекунд.
- **Копирайт-таблица** — все строки интерфейса на английском, включая ошибки, пустые состояния
  и пуш-уведомления. Одна строка = один ключ.
- **Ассеты** — иконки (SVG), логотип, app icon, плейсхолдеры.
- **Чеклист доступности** — контраст, фокус, тач-таргеты, reduced-motion.
- **Открытые вопросы к разработке** — с ответственным и статусом.

## Правила

1. Хендоф не дублирует токены и компоненты, а **ссылается** на
   [`../tokens/`](../tokens/) и [`../components/`](../components/). Скопированное значение
   рано или поздно разъедется с оригиналом.
2. Каждый экран передаётся со всеми состояниями. Экран без пустого состояния не принят —
   для MeetMates пустая колода и пустая лента запросов это норма на старте, а не край.
3. Изменение после передачи фиксируется в changelog внизу этого файла, а не правится молча.
4. Продуктовые инварианты из [`../design-system/`](../design-system/) (геоприватность,
   доступность Report/Block, чат после матча) выносятся в спецификацию явно — их нельзя
   «оптимизировать» на реализации.

## Что этот этап обязан вынести из брифа

Инварианты нельзя «оптимизировать» на реализации — значит они выносятся в спецификацию
явно, а не подразумеваются.

| Решение | Что обязано быть в спецификации |
|---|---|
| Геоприватность | Округление на **бэкенде**, не в вёрстке: точные координаты не доезжают до клиента |
| Гейт верификации `D-03` | Список действий, требующих Verified, и поведение при отказе `D-26` |
| Пересдача безлимитная `D-26` | Явно: таймаутов и счётчиков попыток нет |
| Молчание не освобождает место `D-16` | Правило пересчёта `spots left` описано словами, а не выведено из макета |
| Ограничение по своему полу `D-25` | Проверка на сервере, а не только в интерфейсе |

**Готовность этапа:** каждый экран передан со всеми состояниями; экран без пустого
состояния не принимается.
