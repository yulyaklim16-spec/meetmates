# tokens

Дизайн-токены MeetMates — единственный источник правды по цвету, типографике, радиусам,
теням и движению.

| Файл | Для чего |
|---|---|
| [`tokens.css`](./tokens.css) | CSS-переменные. Подключается в прототип и компоненты. |
| [`tokens.json`](./tokens.json) | Тот же набор в машиночитаемом виде — для инструментов и хендофа. |
| [`site.css`](./site.css) | **Не продукт.** Оформление сайта-документации (ресерч, IA, раздел вайрфреймов). Заморожено 2026-10-07 со старой палитрой, когда продукт ушёл на направление D (`D-61`). |

Значения цвета взяты из брифа ([`../CLAUDE.md`](../CLAUDE.md), §8) — направление D «Стекло», `D-61`. Производные значения
(границы, шкалы, тени, тайминги) помечены комментарием в `tokens.css`.

## Правила

1. **Хардкод цвета в компонентах — ошибка.** Любой цвет приходит из переменной.
2. Нужен новый оттенок — сначала токен здесь, потом использование. Не наоборот.
3. `tokens.css` и `tokens.json` меняются **вместе**, одним коммитом.
4. **Один цветной акцент на экран** — `--action`, только главная кнопка. Всё остальное — серые.
   Текст на `--action` — `--ink-on-action` (тёмный, 5.5:1); белый даёт 3.0:1 и запрещён.
5. **Стекло — только поверх контента:** плавающий таб-бар, метка на фото. На пустом фоне стекла нет.
   Текст на стекле проверяется на светлом и тёмном фото.
6. Тени нейтральные, мягкие и со смещением; цветных теней нет.
7. Контраст текста ≥ 4.5:1. `--ink-400` — только иконки и неактивные вкладки, не текст (3.0:1).
8. Иконки — Solar Bold, залитые, один цвет; размеры `--icon-sm/md/lg`.
9. Тач-таргеты не меньше `--tap-min`.

## Тёмная тема

В v1 не делаем ([`../CLAUDE.md`](../CLAUDE.md), §10), но структура к ней готова: значения
разложены по ролям (ink / surface / semantic), поэтому тема добавляется переопределением
переменных в `:root`, без правок компонентов.

## Что этот этап обязан вынести из брифа

| Решение | Что из него следует для токенов |
|---|---|
| Один акцент на экран | Есть только один цветной токен действия — `--action`; градиента нет |
| Контраст ≥ 4.5:1 | Пары «текст на фоне» проверены скриптом; у токенов в комментарии — коэффициент |
| Стекло только поверх контента | Токены `--glass*` есть, токена «стеклянный фон экрана» нет |
| Тач-таргет ≥ 44px | `--tap-min` существует и используется компонентами |
| `prefers-reduced-motion` | Токены движения имеют вариант с нулевой длительностью |

**Правило:** `tokens.css` и `tokens.json` правятся вместе, одним коммитом.
Хардкод цвета, радиуса или тайминга в компоненте — ошибка.
