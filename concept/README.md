# concept

Визуальная концепция: как MeetMates выглядит и ощущается. Этап между
[`../wireframes/`](../wireframes/) (структура) и [`../design-system/`](../design-system/) (правила).

Направление выбрано — **D «Стекло»** (`D-61`, [`../CLAUDE.md`](../CLAUDE.md) §8): серый фон, белые карточки,
один оранжевый акцент на экран, стекло поверх контента, Geist, живые фото. Выбор — [`concept.md`](./concept.md).

## Что здесь лежит

- **Moodboard** — референсы по цвету, типографике, фотографии, движению. С подписями,
  что именно берём из каждого референса, а не просто «красиво».
- **Key screens** — 3–4 экрана в полном визуале, на которых считывается вся идея:
  swipe deck, event detail, match modal, profile. Остальные экраны потом собираются
  из уже утверждённых решений.
- **Направления** — если сравниваем варианты, каждый лежит в своей папке `direction-a/`,
  `direction-b/` с одинаковым набором экранов, иначе сравнение нечестное.
- **Logo / brand** — знак, написание, иконка приложения.

## Критерии готовности концепта

1. Экран не читается как дейтинг-приложение. Проверка: показать человеку вне проекта
   и спросить, что это за продукт.
2. Текст читаем — контраст ≥ 4.5:1, включая текст на стекле поверх светлого и тёмного фото.
3. Видно, что фото — главный носитель энергии, а не заливка фона цветом.
4. Из концепта однозначно выводятся токены: цвета, радиусы, тени, шкала текста.

## Что этот этап обязан вынести из брифа

| Решение | Как это проверяется на концепте |
|---|---|
| Продукт не читается как дейтинг `D-05` | Показать человеку вне проекта: что это за продукт? |
| Фото несёт энергию, но не решение `D-13` | На карточке первой строкой общие интересы, а не имя |
| Три сигнала доверия помещаются на карточку | Verified · счётчик подтверждённых встреч · признак отзывчивости; ступеней нет `D-49` |
| Одиночество не продаём `D-20` | В визуале и копирайте нет одинокой фигуры у окна |
| Ни намёка на деньги `D-28` | Нет Pro-бейджей, замочков и «скоро платно» |

**Готовность этапа:** из концепта однозначно выводятся токены — цвет, радиусы, тени,
шкала текста; текст читаем при контрасте ≥ 4.5:1, включая текст на стекле.
