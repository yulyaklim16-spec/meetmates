# design-system

Правила, по которым собирается интерфейс MeetMates. Токены отвечают на вопрос «какие значения»,
компоненты — «из чего», дизайн-система — **«когда что применять»**.

## Как подключается

Одним файлом `D-88`:

```html
<link rel="stylesheet" href="design-system/index.css">
```

Отдельных ссылок на `tokens.css` и `components/index.css` в разметке нет: порядок подключения —
свойство системы, а не забота того, кто её берёт. Токены объявляют переменные, компоненты их читают,
и `index.css` держит этот порядок за всех.

| Что | Зачем |
|---|---|
| [`index.css`](./index.css) | Единственная дверь: импортирует токены и компоненты |
| [`tokens.css`](./tokens.css) | Значения двумя уровнями — примитивы и роли, плюс тёмная тема |
| [`components/`](./components/) | Классы кита: 16 файлов, по одному на компонент |
| [`patterns/`](./patterns/) | **Кладки, которые повторяются** `D-94`: восемь композиций, у каждой названы экраны, где она уже стоит. Порог — три экрана |
| [`docs/`](./docs/index.html) | **Страница на каждый компонент** `D-91`: анатомия, варианты и размеры, когда употреблять, правило и антиправило. Там же [«Почему так»](./docs/why.html) — откуда взялся визуальный язык |
| `examples/` | Примеры страниц на системе — пока пусто |

**Источник правды по значениям остаётся в [`../tokens/`](../tokens/)** — `tokens.css` и `tokens.json`
правятся вместе; `design-system/tokens.css` повторяет их двумя уровнями, и расхождение ловит
`node scripts/tokens-audit.mjs`.

## Что здесь описывается

- **Цвет** — роли, а не оттенки: где градиент, где акцент, где danger. Градиент допустим
  только на главных CTA, match modal, бейджах и активном табе.
- **Типографика** — шкала и её применение: что заголовок экрана, что подпись, где предел строк.
- **Сетка и отступы** — базовый отступ экрана 16px, шаг 4px, безопасные зоны iOS, `--screen-max` 390px.
- **Иконки** — набор, размеры, толщина линии, правила парности с текстом.
- **Движение** — тайминги и характер: spring для свайпа, ease-out для переходов,
  обязательный `prefers-reduced-motion`.
- **Фотографии** — как кадрируются фото в карточке и аватаре, что делать при отсутствии фото.
- **Доступность** — контраст ≥ 4.5:1, тач-таргеты ≥ 44px, видимый фокус, порядок табуляции.
- **Тон и копирайт** — см. ниже, для этого продукта это часть дизайн-системы, а не мелочь.

## Копирайт: правило «не дейтинг»

Продукт про дружбу и совместный досуг, а механика заимствована из дейтинга — значит,
фрейм удерживается словами. Из [`../CLAUDE.md`](../CLAUDE.md), §1 и §8:

| Пишем | Не пишем |
|---|---|
| mates, people, crew | singles, matches near you |
| hang out, join, meet up | date, hookup |
| plans, things to do | evening for two |
| Say hi | Start flirting |

Весь UI-текст — на английском. Тон: живой, короткий, на равных. Без восклицательных знаков
через строку и без снисходительности.

## Продуктовые инварианты

Правила, которые нельзя нарушить ни на одном экране:

1. **Геоприватность.** Точка на карте не показывается никогда — только округлённое расстояние
   или район. Меньше 1 км → `Nearby`.
2. **Report / Block доступны везде**, где показан другой пользователь: карточка, профиль, чат,
   список откликнувшихся на запрос.
3. **Чат только после взаимного лайка.** Исключение — отклик на запрос, подтверждённый автором.
4. **Точный адрес — только подтверждённым участникам запроса.**
5. **Никаких платных фич и paywall** в v1.

## Что этот этап обязан вынести из брифа

Дизайн-система — единственное место, где инварианты становятся проверяемыми.

| Решение | Правило системы |
|---|---|
| «Не дейтинг» — гарантия `D-05` | Копирайт-таблица ниже; слово из правого столбца в макете = ошибка |
| Одиночество не продаём `D-20` | Стоп-слова: `lonely`, `alone`, `no friends`, `stuck at home` |
| Про пол говорим о составе `D-25` | `Who can join: women only` — да; `Looking for a girl` — нет |
| Бейджа присутствия нет нигде `D-06` | «Онлайн», «был N минут назад» — запрещены как класс |
| Репутация — только факты | Никаких баллов, звёзд и «процента хорошести» |

**Готовность этапа:** по каждому инварианту есть способ проверить макет, а не только
формулировка намерения.
