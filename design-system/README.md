# design-system

Правила, по которым собирается интерфейс MeetMates. Токены отвечают на вопрос «какие значения»,
компоненты — «из чего», дизайн-система — **«когда что применять»**.

## Что здесь описывается

- **Цвет** — роли, а не оттенки: где градиент, где акцент, где danger. Градиент допустим
  только на главных CTA, match modal, бейджах и активном табе.
- **Типографика** — шкала и её применение: что заголовок экрана, что подпись, где предел строк.
- **Сетка и отступы** — базовый отступ экрана 16px, шаг 4px, безопасные зоны iOS, `--screen-max` 390px.
- **Иконки** — набор, размеры, толщина линии, правила парности с текстом.
- **Движение** — тайминги и характер: spring для свайпа, ease-out для переходов,
  обязательный `prefers-reduced-motion`.
- **Фотографии** — как кадрируются фото в карточке и аватаре, что делать при отсутствии фото.
- **Доступность** — контраст ≥ 4.5:1, тач-таргеты ≥ 44px, видимый фокус, порядок табуляции.
- **Тон и копирайт** — см. ниже, для этого продукта это часть дизайн-системы, а не мелочь.

## Копирайт: правило «не дейтинг»

Продукт про дружбу и совместный досуг, а механика заимствована из дейтинга — значит,
фрейм удерживается словами. Из [`../CLAUDE.md`](../CLAUDE.md), §1 и §8:

| Пишем | Не пишем |
|---|---|
| mates, people, crew | singles, matches near you |
| hang out, join, meet up | date, hookup |
| plans, things to do | evening for two |
| Say hi | Start flirting |

Весь UI-текст — на английском. Тон: живой, короткий, на равных. Без восклицательных знаков
через строку и без снисходительности.

## Продуктовые инварианты

Правила, которые нельзя нарушить ни на одном экране:

1. **Геоприватность.** Точка на карте не показывается никогда — только округлённое расстояние
   или район. Меньше 1 км → `Nearby`.
2. **Report / Block доступны везде**, где показан другой пользователь: карточка, профиль, чат,
   список участников события.
3. **Чат только после взаимного лайка.** Исключение — групповой чат события.
4. **Точный адрес события — только участникам** после Join.
5. **Никаких платных фич и paywall** в v1.
