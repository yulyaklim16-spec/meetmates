Компоненты

Тридцать три компонента, из которых собраны все пятьдесят экранов концепта. Здесь они живые: страница одета design-system/index.css — тем же файлом, что и продукт. Поменяется компонент, поменяется и эта страница; соврать ей нечем.

У каждого своя страница из четырёх частей: анатомия с подписями частей, варианты и размеры, когда употреблять и правило с антиправилом. Композиции из этих компонентов, которые повторяются на экранах, — «Паттерны»; откуда взялся сам визуальный язык — «Почему так».
