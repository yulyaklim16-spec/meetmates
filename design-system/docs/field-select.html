Когда употреблять

Выбор из закрытого списка: «кто может откликнуться» — Anyone · Women only · Men only (§5.4). Пустым он не бывает: значение по умолчанию стоит сразу.

Ограничение всегда описывает компанию, а не искомого человека: Who can join: women only — да, Looking for a girl — нет (правило 6).

Из витрины: Три значения — ограничение отклика на своём запросе (D-25). Открытый список — состояние поля, а не второй компонент. Недоступным он бывает ровно в одном случае: пол не указан, и ограничение поставить не из чего; строка под полем говорит, что сделать. Состояния «не приняло» у него нет — выбрано всегда одно из трёх, пустым он не бывает.
