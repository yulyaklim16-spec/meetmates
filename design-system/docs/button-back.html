Когда употреблять

Возврат с экрана, на который пришли из другого: диалог, карточка события, профиль человека, верификация. Роли взяться не из чего — это не действие, а дорога назад, — поэтому в имени клетки стоит No filling.

Направление обязано читаться без цвета, отсюда голая стрелка. Отключённой она не бывает: уйти с экрана можно всегда.

Из витрины: Возврат: стрелка без круга и без заливки. Роли взяться не из чего, поэтому на её месте в имени стоит No filling. Направление обязано читаться без цвета — отсюда и голая стрелка. Отключённой она не бывает: уйти с экрана можно всегда.
