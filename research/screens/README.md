# research/screens

Скриншоты чужих продуктов для конкурентного анализа ([`../research.md`](../research.md), §4).

## Именование

```
<product>--<flow>--<step>.png
```

Строчные буквы, слова через дефис, разделитель блоков — двойной дефис.

```
bumble-bff--onboarding--01-interests.png
bumble-bff--discover--02-card.png
meetup--events--01-feed.png
tinder--discover--03-match-modal.png
luma--event--01-detail.png
```

`<flow>` — из общего словаря, чтобы экраны разных продуктов сравнивались построчно:
`onboarding` · `discover` · `event` · `events` · `chat` · `profile` · `safety` · `empty` · `paywall`

## Правила

- Скриншоты только мобильные, если продукт мобильный. Десктоп — отдельным флоу `-desktop`.
- Персональные данные с чужих экранов замазывать: имена, фото, переписку реальных людей.
- Скриншот без строчки в таблице `research.md` бесполезен — сначала наблюдение, потом файл.
- Крупные наборы не коммитим целиком: держим только те экраны, на которые есть ссылка в анализе.
